# 🎬 电影评论情感分类系统
English Movie Review Sentiment Classification

---

## 📌 项目简介
基于预训练BERT模型实现的英文电影评论情感分类工具，输入英文评论文本，自动判断情感倾向（`positive`/`negative`）并输出置信度。

## 🛠️ 技术栈
- Python 3.8+
- ModelScope 模型库
- BERT 英文情感分类模型 (`damo/nlp_bert_sentiment-analysis_english-base`)
